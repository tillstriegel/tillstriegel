### the point

i build tools that turn repetitive work into something you don't have to think about anymore.

AI agents, useful CLIs, systems that keep running after you close the laptop. not because everything needs an agent. because some things shouldn't need a human.

my bet: machines can help us produce more with less toil. the dividend should be human—more time, more agency, and more people able to build a good life.

### operating principles

- automate the repetition. keep the judgment.
- use intelligence where it helps. use boring code where it works.
- make systems inspectable, interruptible, and repairable.
- count the hours given back, not the agents spun up.
- prosperity isn't just more output. it's more options.
